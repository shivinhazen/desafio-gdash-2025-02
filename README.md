# GDASH 2025/02 — Challenge Reference Fork

Reference fork of the official [`GDASH-io/desafio-gdash-2025-02`](https://github.com/GDASH-io/desafio-gdash-2025-02) repository.

This repository preserves the challenge specification used during the GDASH 2025/02 selection process. It is **not** the implementation repository and should not be interpreted as original project code authored in this fork.

## Challenge scope

The specification asks for a distributed full-stack weather-data system composed of:

- React + Vite frontend.
- NestJS / TypeScript API.
- MongoDB persistence.
- Python weather-data collector.
- Go worker consuming a message broker.
- RabbitMQ or equivalent messaging infrastructure.
- Docker Compose orchestration.
- Authentication, user CRUD and CSV/XLSX export.
- AI-assisted insights derived from collected weather data.

## Implementation note

The implementation created from this challenge is maintained separately from this public reference fork.
